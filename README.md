# money.thistle.casa

The MoneyThistle website, served by GitHub Pages from this repository.

- Custom domain: `money.thistle.casa` (see the `CNAME` file)
- Cloudflare DNS: `CNAME` record, name `money`, target `moneythistle.github.io`, DNS only (grey cloud), TTL Auto
- Plain static HTML and CSS. No build step. Edit `index.html` and push to publish.
- The MoneyThistle app itself lives at https://github.com/MoneyThistle/MoneyThistle
